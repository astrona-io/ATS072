# Prerequisites

- The `astrona` command-line tool, installed and working (`astrona check` passes).
- A machine that can run a small virtual machine with qemu, with about 2 GiB of free memory. The lab needs no Kubernetes, no Node.js and no internet access inside the virtual machine.
- You can read TypeScript and YAML, you know how Backstage layers `app-config` files and `@visibility` tags, and you know how a backend module uses an extension point.
