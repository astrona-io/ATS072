# Welcome To The Course

This course develops the official Customizing Backstage objectives for Certified Backstage Associate (CBA). The certification uses a multiple-choice examination. The course is independently authored and does not claim to simulate the examination.

Each section starts with its own introduction and learning outcomes. Each module provides goals, developed teaching, a playground, a graded lab and a final summary. Each section ends with a capstone lab and a quiz. Lesson counts follow the subject rather than a fixed number.

The quizzes contain original questions with answer feedback. Technical pages remain draft for review.

Read the explanations and worked examples to identify the responsible component, intended operation and limits of each claim. Use the playground to try each step and the lab to practise it.
