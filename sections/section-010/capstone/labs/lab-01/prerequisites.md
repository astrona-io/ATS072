# Prerequisites

- The `astrona` command-line tool, installed and working (`astrona check` passes).
- A machine that can run a virtual machine started by Astrona.
- You can edit a file in a terminal with `nano` or `vim`, and search with `grep -n`.
- You know `createFrontendPlugin`, `PageBlueprint`, `createBackendPlugin`, `createBackendModule`, extension points and `coreServices`.

The lab starts an Ubuntu virtual machine. The project is in `/home/candidate/backstage-app`. It has no `node_modules` directory and needs no network access: nothing is installed or built.
