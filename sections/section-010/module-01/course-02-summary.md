# Summary

Frontend plugins provide browser-visible features and client integration. Backend plugins provide server capabilities, while backend modules extend one plugin through its supported extension points and services provide shared facilities. Installation must match the application's selected frontend and backend systems. Package availability does not guarantee that a feature is registered, authorized or configured, and moving a credential into a browser plugin never creates a safe trust boundary.
