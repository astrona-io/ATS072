# Customizing Backstage (ATS072)

Certified Backstage Associate (CBA): Customizing Backstage, worth 32% of the official curriculum. This course belongs to ATP014.

Developed reading explains mechanisms, responsible components, examples and limits. Every section has an introduction and every module closes with a summary. Reusable YAML checks contain 5–15 questions per bank. Each module has a playground and a graded lab, each section has a capstone lab and a quiz, and a final domain quiz closes the course. Labs and playgrounds are built untested. Technical content remains draft.
